## Estructura de la Base de Datos

### Esquema [dbo] - ASP.NET Identity
- `AspNetUsers` - Usuarios (con campos personalizados)
- `AspNetRoles` - Roles del sistema
- `AspNetUserRoles` - Asignación usuario-rol
- `AspNetUserClaims` - Claims de usuario
- `AspNetRoleClaims` - Claims de rol (permisos)
- `AspNetUserLogins` - Logins externos
- `AspNetUserTokens` - Tokens de usuario

### Esquema [mnt] - Negocio (nombres desde T-798, script 31; mapeo completo en `docs/diseno/T-798_modelo_produccion.md` 2.2)
- Maestros `ABM_`: `ABM_Lineas` (la "máquina" de planta), `ABM_Equipos`, `ABM_Turnos` (T1 05–13, T2 13–21, T3 21–05),
  `ABM_ProductosMaestro`, `ABM_ProductosSku`, `ABM_TiposFalla` (`CuentaParaIndicadores`), `ABM_DetallesFalla`,
  `ABM_OperadoresLinea` (habilitación del usuario en la línea)
- Producción `PRD_`: `PRD_ProgramacionLinea` + `PRD_ProgramacionLineaTurnos` (plan), `PRD_ExcepcionesHorasDia`,
  `PRD_ParametrosLineaProducto` (presupuesto), `PRD_TurnosProduccion` (el eje: línea + turno + fecha de producción) y sus
  hijas `PRD_TurnosProduccionOperadores`, `PRD_TurnosProduccionProductos`, `PRD_ProduccionesTurno` (real oficial)
- Cámaras `CAM_`: `CAM_Camaras`, `CAM_ConteosMinuto`, `CAM_Paradas`, `CAM_Alertas`
- Detenciones `DET_`: `DET_Detenciones` (cuelga de `TurnoProduccionId`), `DET_HistorialEstados`, `DET_Notas`,
  `DET_AnalisisCambios`, `DET_AnalisisAdjuntos`, `DET_ReglasAnalisis`
- `MNT_Tareas`, Control de Proceso `CPR_*`, Inspecciones `INS_*`, Calidad `CAL_*`
- `Auditoria` (sin prefijo)

### Vistas
- `VW_DetencionesDetalle`, `VW_DetencionesAbiertas`, `VW_DetencionesIndicadores` y `VW_ResumenTurnoActual`
  (re-creadas por el 35 con el turno de producción). La aplicación no las usa: son para reportes.
